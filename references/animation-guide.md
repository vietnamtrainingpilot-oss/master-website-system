## Hard Gate
> **review-animations** returns **Approve** — otherwise Fix Required or Remove Required

## Usage
1. Phase G: Apply motion with animate + review-animations gate
2. Use emil-design-eng for philosophy
3. Select GSAP vs Motion/React based on complexity
4. Always respect prefers-reduced-motion
