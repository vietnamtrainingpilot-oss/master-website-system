# Phase A — Intake & Discovery

## Purpose
Capture project brief, set taste dials, identify relevant skills. This is the **only phase without hard gate output** — its deliverable is the **Design Read** document that drives all subsequent phases.

### Step 2: Set Taste Dials (from 	aste-skill, 	aste-skill-v1)

| Dial | Range | Meaning | Typical Values |
|------|-------|---------|----------------|
| **VARIANCE** | 0–100 | Deviation from defaults | Corporate: 10–30, Creative: 60–80 |
| **MOTION** | 0–100 | Animation intensity | Dashboard: 20–40, Landing: 40–60, Creative: 60–80 |
| **DENSITY** | 0–100 | Information density | Financial: 70–80, Lifestyle: 20–40 |

**Record dial values in eferences/dials.json** — they propagate to all phases.

### Step 3: Skills Discovery
Run workspace-surface-audit to identify available capabilities. Check these skills for relevant patterns:

- creative-director — 20+ methodologies, 3-axis evaluation
- rand-discovery — 8-module interview (purpose, positioning, audience, personality, voice, narrative, founder tension)
- rand-voice — Source-derived writing style profiles
- market-research — Market sizing, competitor comparisons
- keyword-research / seo-audit — Search visibility
- competitor-analysis — Organic footprint, keywords, gaps
- domain-name-brainstormer — Domain ideation
- design-consultation — Audit workflow
- promote-idea — Idea → album/project
- lbum-conceptualizer — 7-phase concept architecture
- lbum-ideas — Backlog management
- i-prompt-research — What people ask AI about niche
- i-visibility-audit — GEO/AEO audit
- prompt-engineering-patterns / prompt-optimizer — Prompt design
