# PPTX / Presentation Guide

This guide covers presentation and slide deck creation using skills from the design-templates catalog.

## Referenced Skills (see \eferences/design-templates/AGENTS.md\)

### Core Presentation Skills
- **html-ppt** — 36 themes, 15 templates, presenter mode
- **html-ppt-presenter-mode-reveal** — Magnetic cards, keyboard navigation
- **slides** — Strategic HTML presentations with Chart.js
- **frontend-slides** — Convert PPT/PPTX to web, visual exploration
- **wowerpoint** — Kawaii NotebookLM slide-deck PDF

### Template Variants
- **html-ppt-taste-brutalist** — Dark CRT brutalist deck
- **html-ppt-taste-editorial** — Editorial taste deck
- **deck-swiss-international** — 16-column grid, Klein Blue
- **deck-guizang-editorial** — Magazine meets e-ink, 10 layouts
- **deck-open-slide-canvas** — 1920x1080 canvas, React components
- **html-ppt-retro-quarterly-review** — Retro quarterly review
- **nanobanana-ppt** — AI-generated presentation templates
- **ppt-keynote** — Apple Keynote-quality slides
- **pptx** — PPTX processing
- **pptx-generator** — Generate PPTX files
- **pptx-html-fidelity-audit** — Audit python-pptx vs HTML

## Usage
When Phase E (Template Selection) identifies a presentation need:
1. Check \eferences/design-templates/AGENTS.md\ for full catalog
2. Select appropriate skill based on style (brutalist, editorial, swiss, etc.)
3. Follow skill's workflow for creation

## Design Systems Integration
Presentations should use tokens from selected design system (Phase D):
- Colors from design system palette
- Typography scale from design system
- Spacing from design system
- Motion tokens for slide transitions
