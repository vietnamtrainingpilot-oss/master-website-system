# Documentation / Content Guide

This guide covers document processing, content creation, and report generation.

## Referenced Skills

### Content Creation
- **article-writing** — Long-form content, guides, tutorials
- **content-engine** — Multi-platform content systems (X, LinkedIn, TikTok, etc.)
- **marketing-campaign** — End-to-end campaign planning
- **copywriting** — Persuasive copy patterns
- **writing-guidelines** — Writing standards

### Document Processing
- **document-hunter** — Find primary source documents
- **docx** — DOCX processing
- **pdf** — PDF handling
- **doc** — Document operations
- **minimax-docx** — DOCX with Minimax
- **minimax-pdf** — PDF with Minimax

### Data Reports
- **data-report** — CSV/Excel/JSON to visual report pages
- **release-notes-one-pager** — Release note generation

### Research
- **deep-research** — Cited research reports
- **autoresearch** — Bounded research loops
- **exa-search** — Neural search
- **visual-research** — Visual research patterns
- **wiki-retrieve** — Vault-local retrieval

## Usage
When content/documentation is needed:
1. Identify content type (article, report, campaign, doc processing)
2. Select appropriate skill
3. Follow skill workflow
